## 💻 Bir Yazılımcının / Yapay Zeka Uzmanının En Büyük CV'si: GitHub

"Bana diplomandan önce GitHub profilini göster." Sözü teknoloji dünyasında bir klişe değil, gerçektir.

<!--more-->

### Nitelikli Bir GitHub Profilinin Özellikleri
- **Kişisel Profil README:** Kendinizi, kullandığınız teknoloji ikonlarını (Shields.io / Devicons) ve aktif projelerinizi tanıtan giriş sayfası.
- **Yeşil Katkı Grafiği (Contribution Graph):** Sürekli öğrenme ve düzenli kod yazma disiplininin kanıtı.
- **Sabitlenmiş Depolar (Pinned Repositories):** Rastgele okul ödevleri değil, baştan sona dokümante edilmiş 4-6 seçkin proje.

---

## 📖 Mükemmel Bir Proje README.md Yapısı
1. **Proje Başlığı ve Kısa Açıklaması:** Hangi problemi çözüyor?
2. **Kullanılan Teknolojiler (Tech Stack):** Kütüphaneler, mimari.
3. **Ekran Görüntüleri / Demo GIF:** Görsel çekicilik.
4. **Kurulum ve Çalıştırma Adımları:** `git clone`, `pip install -r requirements.txt`, `python main.py`.
5. **Elde Edilen Sonuçlar & Metrikler:** Doğruluk (Accuracy), F1-Score, hız vb.

---

## 🛠️ Haftalık Uygulama Görevi

GitHub'da profilinizle aynı isimde bir depo açarak kişisel profil README dosyanızı oluşturunuz ve bir projenizin README dokümantasyonunu tamamlayınız.
