### [sppt-python](https://github.com/yunusserhat/sppt-python)
A high-performance Python implementation of the **Spatial Point Pattern Test (SPPT)** for aggregated count data. Accelerated with sparse-matrix operations and bootstrap resampling to quantify spatial distribution similarity and calculate S-Index metrics.

- {{< icon name="github" pack="fab" >}} **Code:** [github.com/yunusserhat/sppt-python](https://github.com/yunusserhat/sppt-python)
